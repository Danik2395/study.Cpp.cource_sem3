# Formatting Lookup (СТП БГУИР 01-2024)

## Usage
1. Identify: Determine the text element to be formatted (e.g., section heading, simple list, mathematical formula).
2. Search: Find the corresponding category and rule name in the nested lookup structure.
3. Apply: Use the specified document sections ("Where to look") and exact phrasing ("Keywords") to generate or verify the text.
4. Fallback: If the required element is not in the lookup, perform a direct search in the PDF text using standard attention mechanisms and contextual keywords.
